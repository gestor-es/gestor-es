# Сценарии использования

Профили: **A** — autónomo + Beckham, **B** — autónomo в общем режиме IRPF, **C** — Sociedad Limitada.
Статус проживания выбирается в профиле: виза предпринимателя, виза цифрового кочевника, разрешение на проживание для работы на себя (cuenta propia), ЕС / без ограничений.
Источники правил: `kb/*.md`.

Номер присваивается при выставлении. Нумерация идёт подряд и по датам, в формате из анкеты (например FACT-{YYYY}-{NNNNN} → FACT-2026-00001). Данные сторон фиксируются в счёте. |

| 4 | Исправить выставленный счёт | A B C | Только через factura rectificativa (серия R). Причина обязательна. Нужна ссылка на исходный счёт. Черновик можно изменить и удалить. |
| 5 | Отметить оплату | A B C | Дата оплаты в счёте. |
| 6 | Записать расход с чеком (justificante) | A B C | Категория задаёт %, который входит в налоговую базу, и % IVA к вычету. Чек сохраняется в `<data>/receipts`. Медицинская страховка: не больше 500 € в год. Питание: только тот %, который вы укажете (лимиты на день). |
| 7 | Записать взнос RETA | A B C | Категория «Cuota RETA»: B — расход (casilla 0186); A — не уменьшает базу 151; C — вознаграждение администратора в натуральной форме (retribución en especie) (111). |
| 8 | Заплатить испанскому специалисту (profesional) или за аренду офиса с удержанием | A B C | Поле расхода «Retención, которую ВЫ удержали» → Modelo 111 (специалисты) или 115 (аренда). Годовые 190/180 появляются в календаре. |

## Чего сервис не делает (намеренно)

- Не подаёт декларации в AEAT. Подача делается в Sede electrónica (Cl@ve / электронный сертификат). gestor даёт casillas и файл для «Importar». Пользователь нажимает «Firmar y enviar».
- Не создаёт записи Verifactu (обязательно для autónomos с 01.07.2027; объявлен перенос на 10.2028).
- Не считает дивиденды, сбережения (ahorro), детей, ипотеку, региональные вычеты, резерв капитализации (reserva de capitalización), OSS (369), 720/721: только напоминания.
- 349: помесячную разбивку и записи исправления прошлых периодов делают вручную (сервис предупреждает).
